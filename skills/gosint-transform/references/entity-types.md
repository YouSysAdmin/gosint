# Entity types

The built-in entity types of gosint. The PRIMARY field is the entity's identity (`node_key`) and its label
source: two writes with the same type and primary value are one entity.
Kinds: `string`, `int`, `float`, `bool`, `datetime` (RFC 3339 or a date),
`url`, `email`, `object`, `any`, `list<kind>`, `ref:<type>` (a nested
entity as an object, a `location` also as one address line).

Any other key is kept as a custom field (an organization's `vat_id`, say),
unchecked. Custom types an administrator declared in the console
(Admin, Types) are valid too but not listed here: ask for their name
and primary field. This table is generated by `scripts/gen` in the
gosint repository, do not edit it by hand.
