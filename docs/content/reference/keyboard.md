**Cmd/Ctrl** means Cmd on macOS and Ctrl on Linux and Windows. In a sketch,
**Cmd/Ctrl+K** shows the same list. The sketch keys do nothing while you
type in a field or a dialog is open.

## Anywhere in the console

| Keys | What it does |
| --- | --- |
| <kbd>Cmd/Ctrl</kbd>+<kbd>J</kbd> | Jump to an investigation, a sketch, a page or an entity |
| <kbd>Up</kbd> / <kbd>Down</kbd>, <kbd>Enter</kbd> | Move through the jump list and open a hit |
| <kbd>Escape</kbd> | Close the jump list |

## Sketch: mouse

| Gesture | What it does |
| --- | --- |
| Click | Select an entity, opening its details |
| <kbd>Shift</kbd> or <kbd>Cmd/Ctrl</kbd> click | Add to the selection |
| Right click | Menu of the entity, the selection, the relationship or the canvas |
| Double click the canvas | Add an entity where you click |
| Double click a collection | Unfold it |
| <kbd>Alt</kbd> drag from one entity to another | Link them |
| Drag an entity | Move it and keep it there |
| Drag a type card onto the canvas | Add one of that type there |
| Click a type in the legend | Hide or show that type |
| <kbd>Alt</kbd> or <kbd>Cmd/Ctrl</kbd> click a type in the legend | Show only that type, again to show all |

## Sketch: keys

| Keys | What it does |
| --- | --- |
| Hold <kbd>S</kbd> and drag | Select with a box |
| <kbd>Cmd/Ctrl</kbd>+<kbd>A</kbd> | Select every shown entity (Graph view) |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Z</kbd> | Undo your last edit of the graph |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo it |
| <kbd>Escape</kbd> | Clear the selection and close a menu, or close the chat and notes |
| <kbd>Cmd/Ctrl</kbd>+<kbd>B</kbd> | Show or hide the entities panel |
| <kbd>Cmd/Ctrl</kbd>+<kbd>D</kbd> | Open or close the console (log, scans, schedules) |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | Show or hide the notes |
| <kbd>Cmd/Ctrl</kbd>+<kbd>G</kbd> | Sketch settings |
| <kbd>Cmd/Ctrl</kbd>+<kbd>K</kbd> | The list of shortcuts |
| <kbd>Enter</kbd> in **Find an entity** | Focus the first match |

## Quick add

The box that opens on a double click of the canvas.

| Keys | What it does |
| --- | --- |
| <kbd>Up</kbd> / <kbd>Down</kbd> | Move through the suggested types |
| <kbd>Enter</kbd> | Add the entity |
| <kbd>Backspace</kbd> in an empty box | Drop the chosen type |
| <kbd>Escape</kbd> | Close |

## Entity panel

| Keys | What it does |
| --- | --- |
| <kbd>Enter</kbd> while renaming | Save the new name |
| <kbd>Escape</kbd> while renaming | Keep the old name |

## Assistant

| Keys | What it does |
| --- | --- |
| <kbd>Enter</kbd> | Send the question |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | New line |

## Analyses and notes

| Keys | What it does |
| --- | --- |
| <kbd>@</kbd> | Reference an entity |
| <kbd>Up</kbd> / <kbd>Down</kbd>, <kbd>Enter</kbd> or <kbd>Tab</kbd> | Pick an entity from the list |
| <kbd>Escape</kbd> | Close the entity list |
| <kbd>Cmd/Ctrl</kbd>+<kbd>S</kbd> | Save now (analysis page) |

## Flow editor

| Keys | What it does |
| --- | --- |
| <kbd>Backspace</kbd> on a selected wire | Cut it |
